Why does macOS show a warning?

macOS includes a security feature called Gatekeeper that warns you when you open an app that hasn't been notarized by Apple. This isn't a sign that the app is unsafe — it means the developer distributes it independently, outside the Mac App Store.

Tomato is an open-source project. Apple's notarization process requires a paid developer account ($99/year), which we haven't set up yet during the beta. The right-click → Open method tells macOS you trust this app, and you'll only need to do it once.

You can verify everything Tomato does by reading the source code on GitHub. Screen capture is entirely local. Summarization calls go to Anthropic using your own API key — no other telemetry is collected.
